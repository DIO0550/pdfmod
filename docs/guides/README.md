## 読み方

リポジトリを取得し、対象のHTMLファイルをブラウザで開いてください。GitHubのファイル画面ではHTMLのソースが表示されます。
各解説は単体で開け、本文・図・操作例はオフラインでも利用できます。出典リンクの閲覧にはネット接続が必要です。

解説には対象の実装時点を記載しています。PR段階の機能を説明している場合もあるため、手元のコードで利用するときは対象バージョンを確認してください。
