## 読み方

リポジトリを取得し、対象のHTMLファイルをブラウザで開いてください。GitHubのファイル画面ではHTMLのソースが表示されます。
各解説は単体で開け、本文・図・操作例はオフラインでも利用できます。出典リンクの閲覧にはネット接続が必要です。

解説には対象の実装時点を記載しています。PR段階の機能を説明している場合もあるため、手元のコードで利用するときは対象バージョンを確認してください。

## 新しい解説の作り方

新規テーマは [HTMLテンプレート](./_template.html) をコピーして作成します。`_template.html` は解説一覧には含めません。
既存のテーマを扱う場合は、その解説を更新してください。

```bash
# リポジトリルートで実行。new-topicを解説テーマのkebab-case名へ変更する。
cp docs/guides/_template.html docs/guides/new-topic.html
```

1. `{{...}}` の差し替え欄を検索し、タイトル・本文・PDF記述例・図・API・出典・対象バージョンを埋めます。PDF記述やコード中の `<` と `>` は `&lt;` と `&gt;` にします。
2. 役割と全体像 → PDF記述 → 仕様 → 処理の流れ → 具体例 → 実装範囲を基本に、テーマに不要な節を削除します。節を増減したら目次リンクと見出し番号も揃えます。
3. 図の入出力・条件・結果は実際の構造へ置き換えます。分岐が不要なら図を組み替えるか手順リストを使います。図のひな形をPDF共通の仕様として扱わないでください。
4. 操作例は正常・省略や境界・エラーの内容を入れ替えます。不要なら領域ごと削除できます。複製するときはパネルの `id` とボタンの `aria-controls` を一意にします。
5. `data-template-notice` の案内を削除し、本文・コメントを含め `{{...}}` が残っていないことを確認します。
6. PC・小画面で図と文字の重なりやはみ出しを確認し、目次・入力例切り替え・キーボード操作・印刷も確認します。確認できなかった項目は作業報告に明記します。
7. このREADMEの解説一覧へリンクと対象範囲を追記します。

テンプレートには、カタログ解説と同系統の配色・目次・図・比較表・補足欄・入力例の切り替え・小画面と印刷向けのスタイルを内包しています。
JavaScriptが無効な場合と印刷時には、入力例をすべて表示します。外部ライブラリやビルド処理は不要です。
